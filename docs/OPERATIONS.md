# Run and recover

Each instance has its own data_root. The server refuses a runtime inside any Git working tree. Back up SQLite using its backup API, not a copy of a live database file without its write-ahead log. Back up skill sources and object bytes as well as metadata. Restore into a new directory, verify integrity, and switch configuration only after review.

On macOS, `python3 tools/install_service.py --config ../workspace-private/config/instance.json --name default` creates a user LaunchAgent with RunAtLoad and KeepAlive. It restarts after a crash and runs while the account is logged in and the computer is awake. It does not keep a sleeping laptop online. Server logs belong outside Git.

Changing file roots does not delete or move sources. A local artifact promotion preserves the source and verifies copied bytes. Provider changes do not migrate existing objects automatically. No R2 resource or paid service is created by startup.

For an uncertain external action, read the workflow journal and reconcile with the provider. Do not blindly repeat an executing or indeterminate action. A confirmed record requires evidence of the actual result.
